# テスト

## ユニットテスト

`./gradlew testDebugUnitTest` で走る。グラス無しで確かめられるのは次のこと。

| テスト | 確かめること |
|---|---|
| `DirectionTest` | 角度の差（±180° をまたぐ）、しきい値と軸の選び方、既定の符号、判定（向いた・はやい・おそい・サンプル無し） |
| `GameEngineTest` | 拍の時刻、セーフで速くなること、アウトと最高記録、「はやい」と「とれない」が 3 回つづくと終わること、タッチの遷移、放置でホームに戻ること、切断中に送らないこと、始める前に画面を描いておくこと |
| `CanvasScreensTest` | 変わった画像だけ送ること、id ごとの場所が変わらないこと、差し替え中も画像バッファに収まること、繋ぎ直した後に全部送り直すこと |
| `SettingsCodecTest` | 設定の保存と、壊れた値を既定に戻すこと |
| `LibrariesTest` | 「ライセンス」画面の依存ライブラリの一覧に、名前・版・ライセンス・作者が出ること |

## 実機での確認

グラスとスマホが要る。公式アプリを強制停止してから行う。公式アプリと同時に接続できるかは、まだ確かめていない。

1. 初回に同意の画面が出て、同意するまでグラスに何も出ないこと。前の版（同意の版が 1）から上書きで入れたときも、もう一度同意の画面が出ること
2. グラスを選んでつなぐと、グラスにタイトル（「あっち向いて／ホイ」と「2回タップでスタート」）が出ること
3. 「向きの確認と調整」を開き、「今の向きを正面にする」の後に右・左・上・下を向いて、同じ向きが出ること。逆なら入れ替えのスイッチで直ること
4. ツルを 2 回タップすると「3」「2」「1」から始まり、拍が一定の間隔で切り替わって見えること（送信の遅れで拍が詰まったり飛んだりしないか）
5. 矢印が出る拍に合わせて違う向きを向くとセーフ、同じ向きならアウトになること。上下も判定されること
6. 「むいて」の拍の前半で向くと「はやい」、向かないと「おそい」になること。どちらかが 3 回つづくと結果が出ること
7. 遊んでいる間に長押しするとタイトルに戻り、タイトルで長押しすると本体のホーム画面に戻ること
8. 結果の画面で 2 回タップするともう一度始まり、最高記録が更新されること
9. タイトルを 60 秒放っておくと、本体のホーム画面に戻ること
10. 遊んだ後に、文字や矢印の欠片（点や線）がグラスに残らないこと
11. はやい（400ms）まで速くなっても、矢印を見てから向きを変えて逃げることが難しいこと。ゆっくりでは、ホイの拍に合わせて向けば「おそい」にならないこと
12. スマホの画面を消してポケットに入れたまま、数分遊べること（拍が止まったり、まとめて進んだりしないこと）
13. 遊んでいる間にグラスとの接続が切れて繋がり直したとき、グラスにタイトルが出ること
14. タイトル・カウントダウン・結果の画面で、下の行（「2回タップでスタート」「長押しでやめる」「2回タップでもう一度」）が下まで切れずに読めること
15. スマホの画面の「ライセンス」を開くと、NOTICE・Opus の後に「このアプリが使っているライブラリ」の一覧（AndroidX・Compose・Kotlin など）と SLF4J API Module の MIT License が出て、最後に Apache License 2.0 の全文が出ること
